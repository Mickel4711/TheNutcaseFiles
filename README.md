Here you can find Examples of Housing for the ESP32Nut-Server or anything else like ESP-Home Projetcs do asking for a special case.
It combines a ESP32-S3 N16R8 with a W5500 Module. There are two variants of the case with or without a Logo for dual use.
The one with Logo is used for the great Project ESP32-Nut found on Github.
